# Java Swing Calculator

A simple desktop calculator application developed using Java Swing.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear button
* User-friendly GUI

## Technologies Used

* Java
* Java Swing

## How to Run

Open `CalculatorApp.java` in a Java IDE such as NetBeans, Eclipse, IntelliJ IDEA, or VS Code and run the program.
